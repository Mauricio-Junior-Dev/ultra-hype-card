# UltraHype

Site React + Vite para higienização de estofados, com a versão aprovada em preto, vermelho e branco.

## Desenvolvimento

- `npm ci`
- `npm run dev`
- `npm run build` (gera `dist`)
- `npm run preview`

## Publicação na Vercel

Manter o projeto e o domínio existentes. Framework: Vite; build: `npm run build`; saída: `dist`. Uma branch pode gerar uma prévia; a publicação no domínio oficial depende da branch de produção configurada na Vercel.

## Contato e acessibilidade

Todos os botões de orçamento apontam para o WhatsApp +55 (11) 92164-2182. A mensagem é apenas preenchida: o visitante decide enviá-la. Navegação por teclado, menu móvel, preferência por movimento reduzido e limpeza dos eventos no ciclo de vida React.
